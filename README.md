# orange-hrm-qa-demo

Playwright with JavaScript automation framework built using the Page Object Model (POM).
Covers OrangeHRM test scenarios with a clean, scalable, and maintainable structure.

This repository showcases my hands-on expertise in Playwright, JavaScript, Cucumber BDD, Page Object Model (POM), and Playwright Agents. It demonstrates my skills in building scalable test automation frameworks, implementing BDD practices, and leveraging AI-powered testing capabilities for modern QA engineering.
